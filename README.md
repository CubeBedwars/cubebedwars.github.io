# 🌐 CubeBedwars Portal (`cubebedwars.github.io`)

The official landing page and multi-platform distribution hub for **CubeBedwars**.

Live site: [https://cubebedwars.github.io](https://cubebedwars.github.io)

## ✨ Hub Capabilities
- **Instant Web Play**: Embedded 3D Voxel Bedwars game playable directly in the browser with full pointer-lock and fullscreen support.
- **Desktop Installers**: Direct downloads for Windows (`.exe`), macOS (`.dmg`), and Linux (`.AppImage`).
- **Mobile Installation**: Android (`.apk`) distribution and 1-click PWA installer.
- **Game Modes Showcase**: Interactive feature guide for all 14 game modes.
- **Studio Creator**: Built-in 3D voxel map maker showcase.
